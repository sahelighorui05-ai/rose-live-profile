ROSE | LIVE PROFILE — WEBSITE FILES

FILES
- index.html: main responsive profile page
- assets/profile-placeholder.svg: default placeholder image
- assets/profile.jpg: add your own profile photo here (optional)

HOW TO USE
1. Extract the ZIP file.
2. To use your own photo, add a JPG image named profile.jpg inside the assets folder.
3. Open index.html in a browser to preview.
4. Before publishing, edit the three button href values in index.html:
   https://example.com
   Replace them with your own valid, approved destination links.
5. Upload the extracted files to your hosting provider, keeping the assets folder structure.

IMPORTANT
- Rating (4.9) and views (12,800) are demonstration numbers, not real analytics.
- LIVE and ONLINE are decorative labels, not verified status.
- Real view counts/ratings require a backend or analytics service.
- Do not publish private contact information unless you intend it to be public.
